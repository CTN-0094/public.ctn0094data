# First Survey Date

This file contains the dates for the demographics survey in CTN-0027 and
CTN-0030 and the medical-psychiatric history for CTN-0051.

## Usage

``` r
data(first_survey)
```

## Format

A tibble with 3,453 rows and 2 variables:

- **who**:

  |                |            |
  |----------------|------------|
  | *Type:*        | integer    |
  |                |            |
  | *Description:* | Patient ID |

- **when**:

  |                |           |
  |----------------|-----------|
  | *Type:*        | integer   |
  |                |           |
  | *Description:* | Study day |
