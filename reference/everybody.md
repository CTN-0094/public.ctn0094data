# Everybody with any data

This is a list of each person with their original study project.

## Usage

``` r
data(everybody)
```

## Format

A tibble with 3,560 rows and 2 variables:

- **who**:

  |                |            |
  |----------------|------------|
  | *Type:*        | integer    |
  |                |            |
  | *Description:* | Patient ID |

- **project**:

  |                |                                     |
  |----------------|-------------------------------------|
  | *Type:*        | factor (First/Reference level = 27) |
  |                |                                     |
  | *Description:* | CTN project number                  |
  |                |                                     |
  | *Levels:*      | 27, 30, 51                          |
